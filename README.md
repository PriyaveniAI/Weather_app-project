# Weather App

## 🌦 Overview
This project is a simple weather application built using Python.  
It fetches and displays weather information for a given city.

---

## 🚀 Features
- Get weather by city name  
- Displays temperature and conditions  
- Simple and easy to use  

---

## 🛠 Technologies Used
- Python  
- API (OpenWeather or similar)

---

## ▶️ How to Run
1. Install requests:
   pip install requests  

2. Run:
   python weather.py  

---

## 📊 Example
Input: Hyderabad  
Output: Temperature, weather condition
